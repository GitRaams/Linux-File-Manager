# Linux-File-Manager
A Simple File Manager for Linux with Limited Functionality using FreeSimpleGUI with option to show folder sizes!

Uniqueness of this utility is its developed using Google Browser AI-Mode!

Thanks for Google & Gemini and to FreeSimpleGUI for making this possible.

I was wishing to develop this using windows programming (X-Windows for Linux) but am more of terminal based coder!
I was still wondering if this will be possible using FreeSimpleGUI (Technically I know it is possible!).

This File-Manager should work in Windows (Not tested yet)
